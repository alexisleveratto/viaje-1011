Privacy Policy

Viaje F.M. is a personal, self-hosted tool that streams an overnight music radio to its owner's own YouTube channel. This page explains what it does with Google and YouTube data.

Whose account it uses

The app is authorised by, and acts only on, the channel owner's own YouTube account. It is not a public service and does not let anyone else sign in.

What it accesses

Using the YouTube Data API, the app only:

  • creates the nightly live broadcast on the owner's channel;
  • reads the owner's own live stream settings and binds the broadcast to the stream.

It does not read, change or delete the owner's videos, comments, subscribers or any other channel content, and it never accesses other users' data.

What it stores

The only thing kept is the OAuth access credential for the owner's account, stored privately on the owner's own server so the broadcast can be created each night. No viewer data is collected. There are no cookies, trackers or analytics.

Sharing

No data is shared with, sold to, or transferred to any third party. Nothing is stored beyond the owner's own channel and server.

Revoking access

Access can be withdrawn at any time from the Google account's third-party access settings. Viaje F.M.'s use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
